## Problem
Viral claims and forwarded links spread on social media far faster than people take time to verify them—and generic search results rarely separate verified fact-checks from unverified rumors.

## My Role
Designed and built the framework-free frontend terminal, Vercel serverless proxy (`api/check.js`), local Python dev server (`server.py`), and verdict normalization pipeline.

## Solution & Architecture
- **Dual-Stage Lookup Pipeline**: Accepts a raw claim or news URL (extracting the article title automatically), checks an in-memory cache, queries the **Google Fact Check Tools API**, and falls back to the **Tavily Search API** only when no official publisher verdict exists.
- **Clear 3-State Verdict Mapping**: Maps publisher free-text ratings deterministically into three transparent visual statuses—**TERBANTAH** (Refuted), **RUMOR / BELUM TERBUKTI** (Unverified / Related Articles), and **TERVERIFIKASI** (Verified)—while keeping technical errors visually neutral.
- **Zero Client-Side Secret Exposure**: All API keys stay strictly on the serverless backend with built-in rate limiting.

## Result
Deployed a fast, zero-dependency live web utility at **benergasih.vercel.app** with an unmistakable retro-terminal aesthetic and honest source attribution.
