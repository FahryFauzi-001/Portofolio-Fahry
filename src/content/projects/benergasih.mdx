## Problem
Viral claims and forwarded links spread on social media far faster than people take time to verify them—and generic search results rarely separate verified fact-checks from unverified rumors.

## My Role
Designed and built the framework-free frontend terminal, Vercel serverless proxy (`api/check.js`), local Python dev server (`server.py`), and verdict normalization pipeline.

## Solution & Architecture
- **3-Stage Verification Pipeline**: Accepts manual claims or news URLs (extracting article titles automatically with SSRF protection), checks an in-memory cache, queries the **Google Fact Check Tools API** for official publisher verdicts, and falls back to filtered **Tavily Search** + **Gemini AI** (`gemini-flash-lite-latest`) to synthesize evidence-based verdicts for general facts or unindexed claims.
- **Clear 3-State Verdict Mapping**: Maps verdicts into three transparent visual statuses—**TERBANTAH** (Refuted), **TERVERIFIKASI** (Verified), and context-aware yellow states (**ADA LIPUTAN TERKAIT** / **BELUM ADA CEK FAKTA** / **PERLU KONTEKS**)—while keeping technical errors visually neutral and clearly distinguishing publisher verdicts from AI-assisted summaries.
- **Zero Client-Side Secret Exposure**: All API keys stay strictly on the serverless backend with built-in IP rate limiting, URL deduplication, and source filtering.

## Result
Deployed a fast, zero-dependency live web utility at **benergasih.vercel.app** with an unmistakable retro-terminal aesthetic and honest source attribution.
