# Portofolio Pribadi — Muhammad Fahry Fauzi

Website portofolio pribadi **Muhammad Fahry Fauzi** (Mahasiswa Computer Science, Bina Nusantara University) yang dibangun menggunakan Next.js, TypeScript, Tailwind CSS, Framer Motion, dan MDX dengan konsep antarmuka *Floating Orbit* interaktif untuk menampilkan proyek di bidang Mobile (Android), Web Development, Computer Vision, Machine Learning, dan IoT, beserta pengalaman kampus, sertifikat, serta CV.
